## 画框

框原图很粗（框条约占整个框宽的五分之一），作者要细一点、但花纹不能变形：整个框**等比**缩到 0.38（框条约 100 CSS 像素），
不单独压扁哪个方向。拼法照 /谱面分析 的代尔夫特陶框（`FRAME` 上面的注释）：四边各自铺满、角上 45° 斜切；
上下两条边从正中往两头左右镜像排开；左右两条边本边一段、对边翻过来的一段轮流排、接缝淡入淡出（上下镜像的话鸟会倒过来）。
四角的黑褐釉茛苕叶又大又亮，照 chart 那样按斜线留一条带子会透出底下的花，所以单独抠成了 `frame-leaves.webp` 整片盖上。
枕条两头淌着蓝釉，镜像以后成一对对蓝斑，取画面时避开了（`FRAME.split`）。

已知的小毛病：上下两条边是同一段花纹镜像着铺的，放大能看出对称的重复。

- **卡片**：一块白釉陶砖（跟画框一个路子）。圆角，里面一圈钴蓝细线，左上一层釉光，右边淡淡一层难度色；影子画进 canvas 再转成 `<img>`。

  表头是一条白的制服料子，群青字、浅紫的次要字。空位是淡淡一块素坯。
- **柱状图、Rating 三格**：她制服的白，淡金边，里面一道浅紫线（裙摆上的条）。旧曲金柱、新曲蓝柱，顶上的浅色比 best 压深一点；
  均值线用她头发的深靛紫。总 Rating 的颜色用白底的深色档（照 list 主题的象牙纸），17 起是压深的虹极。

## 尺寸、大小、速度

功能代码按 1.5 倍出 JPEG（质量 76），超过 5 MB 在同一页面降到 70、64 重新截（`best.cjs` 的 `RENDER_SCALE`、`maxBytes`）。
真成绩：B50 5886×4038 约 3.5 MB，B30 5286×2922 约 2.4 MB。2 倍会超过 5 MB。

服务器没有显卡（见 `../README.md`「出图要快」）。2026-10-20 在本机把出图进程限制在 1 个核、加 `--disable-gpu`：
B50 整张 5.5～5.7 秒（起浏览器 1.2、排版 1.8、截图 2.5），估计服务器上 19 秒左右，跟竖版差不多。
釉面颗粒先画成位图（`bakeGrain`），50 张卡片的影子画进一张图（`drawCardShadows`），不用 `drop-shadow`。
