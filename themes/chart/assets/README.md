## frame.webp 是怎么做的

用无头浏览器的 canvas 处理（页面在 `../design/`，不进仓库）：

1. **背景和镜面抠成透明**：两样都是低饱和的浅灰，一个从图的四边、一个从中心往外灌。白釉也是浅灰，不卡范围会从外沿描金磨掉的缺口漏进框面，
   所以按量好的直线卡住：背景最多灌到外沿往里 30 像素，镜面最多扩到内口往外 30 像素。边界再往里收 2 像素，去掉灰色毛边；
   内口线以里（含往外 3 像素）一律抠空，内沿变成直边，四个内角几小团没灌到的镜面残留也一起去掉。
2. **去掉顶上的贝壳**：贝壳底座压掉了上边框外沿那道深蓝边（描金线还在），从贝壳左边原图 x 1650–2040 那一段深蓝边
   （连同上面透明的背景）镜像着铺过 x 2040–3340，再把贝壳本身清掉。
3. **拉正**：手工烧的陶框不方正（右边往里斜将近 1°，上下两边向右微微上翘，四边还有 ±20 像素的起伏）。量出外沿四条边、
   各拟合一条直线，交出四个外角（原图坐标 左上 240.4,702.8 / 右上 5158.0,682.6 / 右下 5090.1,4751.7 / 左下 247.8,4816.2），
   双线性拉成 4880×4091 的正矩形。
4. **缩小导出**：先整体缩到 40%（浏览器高质量缩放），再做第 3 步的映射（插值前预乘透明度，免得透明处的灰色渗到边上），
   四周留 12 像素，存成带透明的 WebP（质量 0.92，1976×1660，0.5 MB）。

拉正以后量出来的坐标（`theme.js` 的 `FRAME` 用）：外沿 左 12、上 13、右 1963、下 1647；内口 左 253、上 261、右 1721、下 1407；
四边框宽 240～248。**换图要重新量。**
