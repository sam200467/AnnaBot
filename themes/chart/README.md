# chart：谱面分析图

`/谱面分析` 用的主题（功能代码在 `src/features/chart.cjs`，分数线、容错、Rating、OP 的算法在 `src/score-math.cjs`）。
字体、难度颜料色、评级封印、通关标记跟 best / song 主题一样；画面、画框、底板是这个功能自己的，照西比拉精灵记的
水之巫女ジュナ・サラキア（朱娜·萨拉基亚）做（作者 2026-10-17 一轮轮挑的）：

- **背景是一幅油画**：John Atkinson Grimshaw《夏洛特女郎》（1875，公有领域），整张染成月光蓝（作者在几种蓝里挑的「8B」，
  做法见 `assets/README.md`）。作者要「不太写实」、跟 B50 / 单曲素材一个路子的画。
- **画框是荷兰代尔夫特陶镜框**（荷兰国立博物馆 BK-1960-10，公有领域）：作者要欧洲古典、最好带点海洋元素的，挑了这个，
  要求去掉顶上的贝壳。四条边花鸟各不相同、没有能反复铺的线脚，拼法跟 best 的金框不一样，写在 `theme.js` 的 `FRAME` 上面：
  四边各自铺满、角上 45° 斜切只贴那片茛苕叶；上下边从正中往两头镜像；左右边不能上下镜像（鸟会倒过来），
  本边一段、对边翻过来的一段轮流排，接缝淡入淡出。陶框外沿抠出来有几处不齐，页面底色用外沿那道钴蓝。
- **右边淡淡地叠着朱娜的立绘**（官方立绘，左右镜像：法杖和水晶球在外侧、空着的手朝着正文），不透明度 55%、压一点饱和和亮度，
  左边、头顶、脚下三面渐隐；正文一侧铺一层从深到无的暗幕。
- **底板照朱娜设计**（作者不要 /单曲 的拉丝铁板，要一种照角色重新设计的；字体不变）：
  深水的蓝，上面一层月光透过水面照出的焦散光（`assets/caustics.webp`，上半截亮、往下渐暗）；细金边里面再一道淡青的水线；
  四角是她头饰、水晶球上那种金色四芒星；章节名写在浅蓝菱格缎带上（照她身上那两条缎带，上下金边、右头燕尾），骑在板子上沿。
  难度 / 拟合定数 / 物量 / BPM / 版本 / 谱师几个小格也是这个材质（不挂星星）。

## 正文

照 MiaBot 的谱面分析排（谱面信息 → 分数线容错表 → 白金分那块），中二没有白金分，最后一块换成玩家的成绩和游玩记录。
正文一栏在左边，宽 1340，右边留给立绘。

- **谱面信息**：曲绘 250 见方（细金边）｜曲名一行（放不下先缩、最小 38px，再放不下省略号）；曲师那一行的右边挂对应角色
  （头像小圆章 +「对应角色」+ 名字，单独占一行图就高了；好几个时跟 /单曲 一样一级级写短）；难度定数、拟合定数、物量、BPM、版本、谱师
  六个小格。拟合定数紧挨着难度那格（EazyChu 的体感定数，从 `src/data/fit-diffs.json` 拿，写成 `≈13.50`；拟合表里没有的谱面、
  WORLD'S END 不画这格）。版本写这首歌第一次上线的版本名、去掉 CHUNITHM 前缀（跟 /单曲 一样，`CRYSTAL`、`PARADISE LOST`）；
  版本名太长会截断，不挤掉谱师那格。物量构成一根分段的横条加一排数（TAP 朱红、HOLD 赭黄、SLIDE 群青、AIR 铜绿、FLICK 青白）。
  原来还给比同等级谱面多 / 少的挂「多」「少」，作者说没必要，去掉了。
- **分数线 · 容错**：只列 SSS+、SSS、SS+、SS 四档（S+、S 作者说没必要），行高 76（原来六行、64 高，作者嫌挤）。
  每档：封印｜分数线｜单曲 Rating｜另外全是 J-CRITICAL 时最多几个 JUSTICE / ATTACK / MISS｜你还差（差几分、合几个 JUSTICE，
  到了的打勾、整行压暗）。SS 那档的 JUSTICE 正好等于物量，照写（作者不要「不限」）。右上角一行小字写每个判定扣几分。
- **你的成绩**：左边一列是封印 + 最好成绩、通关标记、单曲 Rating、OVER POWER（/ 上限）、落雪排名；右边是游玩记录曲线。
  最好成绩那个大数字用月光银蓝渐变加暗描边、字号也提了一档（作者 2026-10-18 说跟正文同色的奶白不够显眼，
  换成金色又跟单曲 Rating 混在一起），比下面几行金色的 Rating 更亮、更冷。没绑定、没打过这张谱时整块不画，
  只有上面两块（这时图是 2240×1280，正文竖着居中）。
- **游玩记录曲线**（落雪的单谱成绩历史）：
  - 一次一个点、按时间从左到右等距排（按真实日期间隔会挤成一团），最好那次是金点，六十次以上只画线不画点。
  - 纵轴按「离理论值还差多少分」取对数，SSS+ / SSS / SS+ / SS 几条线差不多等距：按分数直接画的话 100 万往上几乎是平的
    （落雪网页上的图就这样），可那正是打这张谱的人最在意的一段。只画到 SSS+，打过 SSS+ 往上的才画到理论值。
  - 线只画到 SS（作者让去掉 S+、S）。比 SS 低的那几次压进 SS 线下面一窄条，一次 SS 都没到过的才往下画 S+、S 的线。
  - 低于 90 万的不画（多半是被技能强制结束的），右上角写「落雪记了27次，实际绘制23次（忽略＜90万分的成绩）」（作者定的说法）。
  - 日期最多六个，头一个和换年的带年份、年份加粗（作者要的，跟月日分开）。带年份的字宽，会跟旁边的叠在一起，
    所以写上以后量一下，挤的就不写；最后一个（最近一次）一定留。日期由功能代码按北京时间写好（`day`），主题不碰时区。
  - 画不出线的时候（只有一条、对方没开放历史成绩、没拿到）由功能代码写好原因放在 `player.note`，写在曲线的位置。

## 尺寸

宽 2240（原来 2040，图快成方的了，作者要横一点），高跟着正文走：带玩家那块约 2240×1423（1.57 : 1，油画原图是 3 : 2），
不扁过 1.75 : 1。出 JPEG 质量 76，两倍图约 1.5 MB。

## 出图要快（服务器没有显卡）

2026-10-17 在本机把出图进程限制在 1 个核、加 `--disable-gpu` 模拟服务器（做法见 `../best/README.md`），示例数据出三次：
整张 2.6～3.3 秒，截图一步 0.8～0.9 秒（/单曲 同样条件约 4 秒）。

- 焦散光是一张平铺的图，不是 SVG 噪声（SVG 滤镜背景每块都要现算，见 `../README.md`「出图要快」）。
- 画框只用 `clip-path`、`mask-image` 和 `object-view-box` 拼，没有滤镜；框的影子是 `box-shadow`，不是 `drop-shadow`。
- 立绘的 `filter` 只有饱和、亮度两项，封印的投影只有五枚。

## 素材

见 `assets/README.md`（油画、画框、立绘、焦散光各自的来源和处理）。处理画框、生成焦散光、生成示例数据的页面和脚本在 `design/`（不进仓库）。

## 数据

`src/features/chart.cjs` 的 `buildData` 给出，形状看 `examples/preview-data.json`（853 MASTER，曲目是真的，成绩、游玩记录、排名是编的）。
版本名按曲库的版本表换成短名（`song.version` → `CRYSTAL`），拟合定数由 `fitDiffs`（`src/data/fit-diffs.json`）按曲目 ID + 难度取
（`chart.fitConstant`，拟合表里没有是 `null`），都在 `buildData` 里一并算好。
示例数据由 `design/make-example.cjs` 用 `buildData` 生成；加 `--real <曲目 ID> <难度>` 用 `.env` 的个人密钥拿作者自己的真成绩，
写到 `data/try/`（只留本机）。
