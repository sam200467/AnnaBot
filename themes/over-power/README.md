# OVER POWER 进度：蕾娜斯

`/OP进度`（`src/features/over-power.cjs`，算法在 `src/over-power.cjs`）：全曲 OVER POWER 按分类、版本、等级拆开的进度，
下面是底色（蓝底、金底这些）的条件和推荐游玩（OP 还能涨最多）的谱面。

作者 2026-10-23 选的：角色蕾娜斯、背景丘奇《荒野暮色》稍微调紫（三档里的中间一档）。画框先用了大都会 1975.1.2292 紫水晶箱式框（P1V），
看过初稿后说换成 1975.1.2169 乌木蓝玻璃箱式框调紫（P2V）试试，现在用的是 P2V（P1V 留在 `assets/frame-p1v.webp`，改
`design/prepare-materials.py` 的 `CHOSEN` 就能换回去）。候选和比较图在 `data/bg-candidates/over-power/`（角色候选、背景候选、
画框候选、01 调紫对比），只在本机。

## 算法和图上的说明

- 每首歌只算 OP 最高的那张谱面（红谱也可能是它），满 OP 按这首歌最高的定数算（黑谱比紫谱高时是黑谱）；WORLD'S END 不算。
  等级那栏只算紫谱、黑谱，每张各算各的（同一首歌的紫谱、黑谱落在各自的等级），只列 10～15+。原来照游戏的等级文件夹连红黄绿也算，
  作者看不懂「每张谱面各算」、红谱混进 14 这些格子，2026-10-23 改成只算紫黑谱，标题条注明「只算紫谱、黑谱」。
- 游戏的分母只算已经解锁的歌，落雪不知道谁解锁了哪些。作者定的：一律按全部曲目已解锁算，页脚写明
  「按全部曲目都已解锁计算（落雪不知道哪些歌你还没解锁），可能跟游戏里的数值有出入」（作者要求标注）。
- 「打过」= 拿到了 OP。被技能强制结束的记录 OP 是 0，当没打过，不进「打过的」那排。
- 底色的条件是玩家总结的（VERSE～X-VERSE-X）：四档都要 Rating 16.00；蓝底（游戏里是银）紫谱黑谱全部 S，金底 S+ 和 OP 97.50%，
  铂底 SS 和 99.00%，虹底 SSS 和 99.50%。游戏里已经拿到的那档和它下面的都写「✓ 已达成」（信游戏的），更高的档才按全解锁算还差几张。
  落雪的 `rating_possession` 是 `normal` 时写「无底色」。抬头一行「四档都要 Rating 16.00 以上（你的是 17.01）」：够了标绿、不够标红
  （共用色阶的 tier-green / tier-red），不写「够了」。

## 角色

蕾娜斯（レナス・オルスキュラ，Lenas Olscura）：土之国奥伦选帝侯家的长女，为了跟发了疯的母亲一起生活，进学院去夺「绝对的权力」，
立誓要站上顶点。曲目〚回帰〛 ～Scherzo ~フォルトゥーナの悪戯~（日服 2025-12-11 加入，国服还没有，落雪的角色表里也没有她），
立绘リウイチ。作者把剧情原文存在本机 `F:/剧情存档/西比拉精灵记/レナス・オルスキュラ.txt`。
官方全身立绘 `Lenas_Olscura_Fullbody.png`（CHUNITHM Story Wiki，900×1000，透明底，SEGA 的图、不是公有领域，只在本机和服务器上用），
裁掉四边透明后 630×983。配色：黑色军装、银白的头发和饰边、紫色的领结和垂饰。

## 版式（横版 2700×1780，JPEG 76、1.5 倍，约 1.4 MB）

- 画框宽 88，是按画布拼好的整张图（`assets/frame.webp`）；油画垫到框下 4px。
- 右边：蕾娜斯按高度放大到 1290、不透明度 0.6，脚落在右下角的暗林里；名片板（照 `/推分记录`）在她头顶的天空里。
- 左边内容区 132～1730：
  - 抬头：「OVER POWER」、全曲 OP 百分比（92px，颜色照游戏）、OP / 满 OP、拿到 OP 的歌几首。
  - 三栏进度条：分类（七行、一行两层，顺序照游戏里的分类文件夹）、版本（二十行）、等级（十二行，标题条注明「每张谱面各算」）。
  - 下面一排：底色（四档一行一档，下一档那行垫一层淡紫）、推荐游玩（原来叫「还能涨最多」，作者改的名）：两排各 6 张曲绘。
    没打过的按满 OP 排、画定数最高的那张；打过的在打过的几张谱面里挑「推满这首歌的 OP 能涨最多」的那张，按能涨多少排，
    画的就是这张谱面和它的真实分数（被技能强制结束的低分也照写；作者不要「这张没打过」）。曲绘右下角写定数、垫难度色，
    下面写还能涨多少。
- OP 百分比的颜色跟底色的门槛一致（作者 2026-10-23：照游戏 70/80/90/95 的分档，96% 就成了虹，会让人以为够虹底了）：
  默认蓝，97.50% 起金、99.00% 起铂、99.50% 起虹。金、铂、虹直接用共用色阶（`shared/rating-tiers.css` 的 tier-gold /
  tier-platina / tier-rainbow），色阶表里没有蓝，用虹那条渐变里的蓝 `#a8c9e7`（主题里的 `.op-blue`）。底色那栏四档的色块用同一套颜色。
- 底板照她的衣服：黑色军装做底、银白细线做边，标题条和进度条是紫色的领结。

## 素材（`design/prepare-materials.py` 生成，都是对原图的裁切、缩放、调色）

- `painting.jpg`：Frederic Edwin Church《Twilight in the Wilderness》（1860，克利夫兰艺术博物馆，公有领域，Commons 原图 5000×3115），
  裁掉扫描的暗边，盖一层 `#5b3a8c`、color 混合、不透明度 32%，缩到 3800 宽。
- `frame.webp`：现在是 P2V（`frame-p2v.webp`）：大都会艺术博物馆 Robert Lehman 收藏 1975.1.2169（罗马，19 世纪仿 17 世纪初的乌木箱式框，CC0）：
  外圈乌木线脚、一圈斜面的蓝玻璃、每条边正中一个嵌红白杂色石和虎眼石的花饰。只取右下角：下边条、右边条各取「从花饰正中到角块」
  连续的一节，一正一反地接（原件花饰和角之间只有很短一段玻璃，所以拼出来花饰一个挨一个，上下各 15 个、左右各 7 个）；
  框宽按「一条边正好排整数节」反推，约 91～95。先试过在花饰之间另补一段玻璃（别处取的玻璃 + 拉长的线脚），明暗对不上、
  每个接头一道缝，没用。最后整件盖 `#6a3a9c`、color 混合、不透明度 70%。
- `frame-p1v.webp`：P1V，大都会艺术博物馆 Robert Lehman 收藏 1975.1.2292（罗马，1880–1900，仿 17 世纪初的乌木箱式框，CC0）。
  照片只有右下角是正面拍的，只取右下角：角块原样，下边条、右边条各取「半个椭圆 + 一段水晶板」一节往中间一正一反地接
  （接缝两边是同一列像素），凑不齐的长度从水晶板靠椭圆那头裁、不压花纹；再把右下这一角镜像到另外三个角，上下各 13 个椭圆、
  左右各 7 个。最后整件盖 `#6a3a9c`、color 混合、不透明度 55%。
- `lenas-fullbody.png`：见上面「角色」。
- 调色用的是 W3C 合成规范的 color 混合（SetLum），跟候选图里浏览器预览的一样；离线烤进图里，出图时不再混合（服务器没有显卡）。
