# best：B30 / B50 / AJ30 成绩图

`/b50`、`/b30`、辅助表 `/aj30` 用的主题（功能代码在 `src/features/best.cjs`、`src/features/aj30.cjs`）。风格照中二节奏的「西比拉精灵记」（シビュラ精霊記）：

- `/aj30` 跟 `/b30` 是同一套版式：一栏 30 首，只挑 AJ（含 AJC）的谱面、不分新曲老曲。章节名是「全曲 AJ」、
  缎带和图表标题写「AJ 30」、页眉的统计格也是「AJ 30」，跟 `/b30` 的「全曲 / Best 30」区分开；新曲照样带 New 标记。
  这是辅助用的表，不进 QQ 输入框的指令面板。
- **整张图是一幅镶在金框里的画**：最外面是洛可可金色画框（`assets/frame.png`），框里一圈羊皮纸，画面是撕开、烧焦的边，
  跟这个系列的曲绘一样。画里上半截是五位巫女（`assets/sibyls.webp`），往下沉进黑暗；最底下是着火的战场（`assets/battlefield.webp`）。
- **画框是拼出来的**：原图框的比例跟成绩图差太远，四个角、每条边中间的雕花原样缩小贴上去，平直的线脚取原图里一段，
  一正一反交替铺满（上下两条边用左右的线脚转 90°）。框比原图窄很多（作者嫌原图的边太宽）。坐标在 `theme.js` 的 `FRAME`。
- **页眉左边是柱状图**：一根柱子一首歌的单曲 Rating，旧曲金色、新曲火色，虚线是这一栏的均值。
  纵轴不从 0 开始，而且每一栏用自己的纵轴、按这一栏的分数段收紧（B50 的旧曲刻度在左、新曲在右）：
  一栏几十首常常只差零点几分，旧曲新曲之间又能差一两分，共用一根轴时柱子全一样高。背后是一个法阵（四精灵的符号、八芒星，
  外圈的卢恩字母转写的是 SIBYLLA · SPES ANIMAM TENET · ANNA MARGARETE），从图表板子的上边和右边露出来。
- **页眉右边**：玩家的名牌版（落雪的图，「★转生 Lv.等级 名字」和称号照游戏里的位置叠上去）、角色头像、
  挂在头像下面的段位勋章（`../shared/icons/class_emblem/`）、Rating 和两栏的均值（格子上只写 Rating / Best 30 / New 20）。
  三格一样高，右边两格的均值字号小，数字在标签下面剩下的高度里居中，水平中轴跟 Rating 那个大数字对齐
  （2026-10-19 作者发现 17.31 / 16.57 比 17.01 高出一截）。
  Rating 的数字按游戏里的 Rating 色档上色（绿、橙、赤、紫、铜、银、金、铂、虹，17.00 起是更浓的虹极；
  色相照游戏，亮度按暗底提了一档，纯绿那种在暗底上看不清；虹极还是上暖下冷的竖渐变）。只改颜色，字体和星都不动。
- **每首歌是一张旧纸片**：左边曲绘，右边一栏依次是曲名（只写一行，字大，放不下就用省略号）、分数、通关标记、「定数 › 单曲 Rating」。曲绘框和底下的条用难度的颜料色（铜绿、赭黄、朱红、紫、黑红），单曲 Rating 用干掉的血色。
  带希腊字母的曲名（2026-10-18 查落雪曲库只有 6 首，最长 11 个字）按两倍字号排、再 `zoom: 0.5` 缩回 26px：霞鹜文楷的 Ω 右边那条腿很细，
  26px 时会被栅格化吃掉，「ΩΩPARTS」第二个 Ω 看起来像被挡了一块（2026-10-18 作者发现，放大就正常）。
  字重写 900，缩回来才跟别的曲名的 700 一样粗；这类曲名都很短，不会碰到省略号。
  评级是一枚金属封印（形状还是不规则的封蜡边）：SSS+ 带虹彩的金、SSS 金、SS+/SS 银、S+/S 铜、AAA 往下发黑的铁。
  原来是红蜡、紫蜡，跟 EXPERT 的朱红、MASTER 的紫分不清（2026-10-16 作者反馈），金银铜不跟任何一种难度色撞。
  通关标记是实心的小牌子：FC / AJ / AJC 是铜、金、珠光的金属牌，HARD / BRAVE / ABSOLUTE / CATASTROPHY 是朱、紫、群青、黑底金字的缎带签。
  标记的字 19px；AJC + CATASTROPHY 这种一行放不下时整行缩小（最小 15px），还放不下才去掉最后的 FULL CHAIN。
- **章节名**写在缎带横幅上（借了 Lanota 支线第二章章节封面的缎带），左边写这一栏打了几首（「旧版本曲目 30 / 30 首」）。
  右边原来写着均值和地板，跟页眉的格子重复，2026-10-16 删了。
  B50 两栏的交界横着铺一整排金色花饰：花和卷草交替，卷草一正一反，整排左右对称（`assets/ornament.png` 当遮罩，填主题的金色；
  朵数按宽度挑，见 `theme.js` 的 `drawFrieze`）。
- **页脚**只有格言（Segoe Script，写得大，填满底下的战场）和落款。*Spes animam tenet* 是拉丁文「希望系住灵魂」—— 西比拉世界的规矩：希望把灵魂留在身体里，绝望让灵魂离开。
- **字是手写的**：正文只用霞鹜文楷 Medium（`fonts.css` 的 `Anna Hand`）。它一个字体就有简体、繁体、日文汉字、假名和西文，
  曲名里几种文字混排时大小、笔迹都对得齐；只缺 ✪，由 Segoe UI Symbol 补。选它的经过见 `../shared/fonts/README.md`。
  单曲分数、定数、单曲 Rating 和格言用 Segoe Script（`Anna Script`），作者要这几处数字跟正文区分开。
  文楷没有粗体：曲名、章节名（旧曲 / Best 30）、章节左边的曲数、称号、Rating 那几格的标签、图表上除「Best 50」以外的字、
  通关标记、评级用 `--hand-bold`（`Anna Hand Bold`，浏览器在 Medium 上描粗），其余照旧是 Medium。
  名牌版上「★转生 Lv.等级」一样大（34px），名字 36px。

撕边、封蜡、余烬、法阵都是 `theme.js` 用固定种子的伪随机数现画的，纹理是 SVG 噪声，同一份数据每次出图都一样。

## 出图要快（服务器没有显卡）

服务器上出图全靠 CPU，比本机慢三四倍：2026-10-16 服务器出 B30 用了 32 秒，B50 截图一步超过了 30 秒、出图失败。
本机把出图限制在 1 个核、关掉显卡加速（`--disable-gpu`）模拟，挨个去掉效果量出来的大头，改成了下面的做法，样子不变
（新旧两张图逐像素比过，平均差不到 1/255），1 核上 B50 从 12～14 秒降到 6～7 秒，截图一步从 10 秒降到 3 秒：

- **纹理先画成位图**（`bakeTextures`）：`--grain` `--mottle` `--soot` 直接当 CSS 背景时，浏览器每画一块都重算一遍噪声。
  出图前画进 canvas、转成 PNG 再当背景。转 PNG 是费时的那步，所以只有纸纤维按出图倍率画，霉斑、烟画得粗一点。
- **影子画成图片**（`shadowImage`）：撕边一圈的焦影原来是 `.rim` 上两层 `drop-shadow`（等于把整张图模糊两遍），
  五十张卡片各有一层 `drop-shadow`。现在把撕边的多边形画进 canvas、模糊一次，转成 `<img>` 垫在下面。
  不直接把 `<canvas>` 放进页面：它会单独占一个合成层，图这么大时上面那层有些块来不及画，截出来一块块缺着。

以后改效果时，大面积的 `filter`（`drop-shadow`、`blur`）和 SVG 滤镜做的背景都要小心。

## 数据

`src/features/best.cjs` 的 `buildData` 给出，形状看 `examples/preview-data.json`（B50）、`examples/b30.json`（B30）和
`examples/aj30.json`（AJ30：`mode` 和章节 key 不同，示例里每首的 `fullCombo` 都是 AJ / AJC）。示例数据的曲目是真的、分数是编的。
柱状图直接用各栏的 `scores[].rating` 和 `average` 画，不另要数据。

## 预览

```
npm run theme -- best                                                  实时预览（B50 的示例数据）
npm run preview -- best --out themes/best/previews/b50.jpg               正式出图流程渲染 B50 示例
npm run preview -- best themes/best/examples/b30.json --out themes/best/previews/b30.jpg
npm run preview -- best themes/best/examples/aj30.json --out themes/best/previews/aj30.jpg
```

出图是 2040 CSS 像素宽（内容 1824 + 羊皮纸 + 画框）、两倍输出，JPEG 质量 76。
B50 大约 4080×6410、4 MB，B30 / AJ30 大约 4080×4390、2.7 MB（作者要求单张在 5 MB 以内）。
预览的输出路径写 `.png` 就出 PNG，但这个主题纹理多，PNG 有十几 MB。
