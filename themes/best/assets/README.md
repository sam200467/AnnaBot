# best 主题的素材

这里的图由作者自己准备，**不进仓库**（只有这份说明进仓库）。缺了也能出图，只是少一层背景或装饰。

| 文件 | 用在哪 | 说明 |
| --- | --- | --- |
| `sibyls.webp` | 页眉背景 | 西比拉精灵记的五位巫女躺在花丛里（官方 2021 年活动「シビュラ精霊記 ～Strive Against Fate～」的插画，708×708）。主题会压暗、褪色、往下渐隐；图小，放大后有点糊，当远处的壁画看 |
| `battlefield.webp` | 页脚背景 | 西比拉精灵记风格的战场：紫色的烟、着火的地面、插在地上的剑（1086×611）。图四周自带一圈羊皮纸边，主题会裁掉 |
| `frame.png` | 最外面的画框 | 作者找的洛可可金框照片（1271×1920），白底抠成了透明。主题按 `theme.js` 里 `FRAME` 量好的坐标切成角、边中间的雕花、平直线脚拼起来，**换图要重新量坐标** |
| `ornament.png` | B50 新旧曲交界的一排花饰 | 作者找的金色花饰（图片来源：千图网 58pic.com，原图是竖的「花、卷草、花」）。做成了一张花和卷草左右并排的图（1549×578），主题拿它的形状当遮罩、交替着横铺一整排，颜色用主题自己的金色。图上各块的坐标写在 `theme.js` 的 `FRIEZE`，**换图要重新量** |

`frame.png`、`ornament.png` 抠白底的做法：从图的四边往里找「白、不鲜艳」的像素当背景变透明；
平涂金色的花饰按蓝色通道离白色多远算透明度（边缘的抗锯齿能保住）。

`ornament.png` 接着这样做：去掉底部的来源水印条，顺时针转 90° 成横的；原图右边那朵花比左边的低 27 像素（原图本身有点歪），整张转正 1.07°；
按连通块分出左边的花、中间的卷草（右边那朵花跟左边的一样，不要），两块按原来的上下位置并排放，中间空 40 像素，主题按矩形裁的时候不会裁进别的块。
