# year：年度总结图

`/年度总结`（`src/features/year-review.cjs` + `src/year-review.cjs`）的主题。原初的巫女艾薇妮娅斯（原初の巫女アヴェニアス），
背景是作者选的 13 号：赖特《那不勒斯海边的岩洞（日落）》，画框是作者选的 A4：荷兰国立博物馆 BK-15994 红玳瑁乌木波纹镜框。
候选和来源在本机 `data/bg-candidates/avenius/`（`素材候选.md`、`画框候选.md`），素材说明见 [assets/README.md](assets/README.md)。

## 数据

落雪 `user/chunithm/player/year-in-review/{年}`（只有玩家接口有，要授权）。图上的数都是**上传记录**的条数：
同一首歌一年里上传几次就算几次，评级、全连、难度分布也按上传记录数，每种分布加起来都等于上传总数（2026-10-21 拿真数据核过）。
图上一律写「上传」，不写「游玩」。整理在 `src/year-review.cjs` 的 `buildYearView`，字段说明在那个文件开头。

- Rating（年内第一次 → 最后一次上传）：落雪 2025 年存的快照里没有新曲 N20，照落雪网页按旧算法 (B30 + 最高一首 × 10) ÷ 40，
  页脚注明；有新曲时按 VERSE 的 (旧曲 B30 + 新曲 N20) ÷ 50。两位截断，按共享色档上色。
- 上传最多的歌：最多 10 首，次数多的在前，同样多按曲目 ID 从小到大（照落雪前端）。前三名上领奖台（第一名在中间），4–10 名两列。
- 每月上传次数统计：12 格，每格写次数和当月上传最多的前三首曲绘（落雪的 `player_song_timeline`），没上传的月份淡掉写「—」，
  格子底下一道细条按次数比例。
- 评级/全连统计：按包含关系数（SSS 含 SSS+，SS 含 SS+ 以上，S 含 S+ 以上；FC 含 AJ、AJ 含 AJC，AJC 是 0 不列）。
- 难度分布：按定数档从低到高的小柱状图，0 条的档不画。
- 2024 年的数据没有这几项分布和 Rating 成长：那几块整块不画。
- 没画：每小时上传分布、BPM、曲风、版本占比，落雪网页上的标语。

## 版式

- 固定横版 2700×1780（跟 /同步记录 一样），JPEG 76、1.5 倍输出（4050×2670，真数据约 1.3 MB）。
- 画框是按画布拼好的整张图 `assets/frame.webp`（`design/prepare-materials.py`）：四角 + 边条同一个缩放比，边条平铺、末段只裁不压，
  每隔一段翻一次（照片里一条边两头明暗不一样）。框宽约 88。改了画布尺寸要重跑脚本。
- 艾薇妮娅斯在右边那一栏，60% 不透明度，等比缩到 870 宽、脚落在洞口的地面上（作者 2026-10-21 要缩小一点，原来 990 宽）。
- 名片板（名牌版、称号、★转生 Lv.等级 + 名字、头像、段位、总 Rating，照 /推分记录）放在**左栏抬头的右边**：
  TA 举着剑，画面右上角被剑和缎带占了。
- 底板照 TA 的衣服：表格底是黑外套的衣料（从立绘裁的一小块，`theme.js` 的 `textures`；左片带盘扣，裁到会平铺出一排「∞」，
  所以裁右片金边和盘扣之间那块），边线是旧金，标题条是胭脂红披风。
- 页脚贴着画框下沿摆（作者 2026-10-21 嫌跟着内容走太靠上）。
- 曲名一行放不下先缩字（最小 23px），还放不下才省略号。
- 虹极（17 起）的竖渐变按数字定位：总览里的 Rating 是 flex 里的块，背景盒是行高 1.25 em，所以写了 `--tier-lh: 1.25`；
  漏写时颜色整体往下错（作者看出 17.03 颜色不对）。数字不要另写 `color`：比 `.tier-*` 具体，会盖掉金、银这些纯色档。
