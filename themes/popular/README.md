# popular：热门谱面图

`/热门谱面`（`src/features/popular.cjs`）的主题。原初的巫女萨拉基亚（原初の巫女サラキア），
背景是作者选的 03 号：透纳《狄多建设迦太基》（原始亮度），画框是作者选的荷兰国立博物馆 BK-1971-122 乌木银丝花镜框。
候选和来源在本机 `data/bg-candidates/salacia/`（`素材候选.md`、`frames/`），素材说明见 [assets/README.md](assets/README.md)。

选画的由来：萨拉基亚是港城提亚奥奇亚（Tioquia）贵族宅邸里的女仆。起义那晚她招来暴雨，之后成了新的君主，
要把提亚奥奇亚建成她心中的理想国（剧情前半「Salacia, Original Sibyl」，后半在「Water Elemental」）。
狄多在水边建她的迦太基，正好对上；萨拉基亚身后是画里的神殿。

## 数据

落雪 `chunithm/song/popular?range=week|month`（文档没列，落雪首页「热门曲目」用的就是它）：全站近 7 天、近 30 天上传最多的前 10 张谱面。

- 按谱面排：同一首歌的 MAS、ULT 分开算，EXP、WORLD'S END 也会上榜。WE 没有定数，写难度字和星数。
- 公共接口，但响应包了一层 `{ success, data }`（`lxns.cjs` 照样解包）。
- 时段是北京时间的整天，`period_end` 是北京时间零点（不含），图上写成 `10/15 – 10/21`。
- `updated_at` 每小时 05 分变一次，抬头写「落雪 … 更新」。
- `previous_rank` 是上一个同样长的时段里的名次：画成 ▲ / ▼ / —，`null` 是新上榜，画 NEW。

玩家的成绩（绑定了才有）：

- 授权绑定一次读 `/scores`。
- 好友码绑定按曲目读 `/bests?song_id=`：两张榜去重后最多 20 首，3 个一批。
- 同一张谱面取最高分。单曲 Rating 用落雪给的，没有就按当前定数现算（`score-math`）；WORLD'S END 没有 Rating。

没绑定的人也能用：只看榜，不画成绩那一栏和名片板。`@某人 /热门谱面` 看对方的成绩（走开发者接口，受对方在落雪的第三方开关管）。

## 版式

- 横版 2800×1780，JPEG 76、1.5 倍输出（4200×2670，示例和真数据都约 1.4 MB）。
  油画原图的比例只要 2635 宽，右边站不下萨拉基亚，所以按 `minWidth` 加宽，油画上下裁掉一点（`object-position: center 45%`）。
- 出图快：本机单核 + `--disable-gpu` 约 2.6 秒（起浏览器 1.1、排版 0.9、截图 0.6），按服务器慢 3.4 倍算约 9 秒。
  没有大面积的 `filter`，名片板那两处 `drop-shadow` 只盖一小块。
- 画框由 BK-1971-122 的三块拼成：
  - 左右立柱一节接一节，隔一节上下翻；右边整条左右翻，花样的外沿朝外。
  - 上下横档从中间往两边对称地接：原件底边就是在中间反向扭的。
  - 四角是原件脚上的方墩。
  - 四边同一个缩放比 0.33（立柱宽 84、横档高 61、方墩 84×159），不拉伸花纹。
  - 框是 `theme.js` 的 `buildFrame` 在页面里一节一节放 `<img>`，不是拼好的整张图：改画布尺寸不用重跑脚本。
- 萨拉基亚在右边那一栏，60% 不透明度，上下左右都居中（照 /同步记录、/年度总结）。
- 左边是抬头（标题 + 落雪的更新时间），名片板放在抬头右边：她的冠在右栏最上面。名片板照 /年度总结。
- 抬头和页脚的字压在油画上，左上和底边各压一层渐变。两张榜是浅色底，不用整片压暗；油画本身不调亮度。
- 两张平行的榜（近 7 天、近 30 天），每张 10 行：
  - 名次：前三名是金、银、铜的圆牌，下面一行是升降（▲ 绿、▼ 红、— 灰、NEW 金签）。
  - 曲绘，带难度色的框。
  - 曲名；难度 + 定数 › 单曲 Rating；曲师。
  - 绑定了再加一栏：玩家的分数（照成绩卡片，Anna Script Heavy、墨色）、评级封印、通关标记。没打过写「未游玩」。
  - 表头右边写「打过 n / 10」。
- 配色照萨拉基亚的衣服：表格底是浅灰白的长裙，表头是深褐近黑的内裙，金线是那串金色短剑。
- 字放不下时：
  - 曲名先缩到 23px，再放不下用省略号。
  - 分数最小缩到 30px。
  - 通关标记先缩到 15px，再去掉最后一个。
- 一张榜是空的写「落雪这段时间的榜是空的」；两张都空就不出图，直接回文字。

## 预览

```powershell
node tools/render-preview.cjs popular --out themes/popular/previews/preview.jpg --scale 1.5
node tools/render-preview.cjs popular themes/popular/examples/unbound.json --out themes/popular/previews/unbound.jpg --scale 1.5
```

`examples/preview-data.json` 是真的热门榜（2026-10-22）配虚构的玩家和成绩，曲绘写 `lxns:` 引用；`unbound.json` 是没绑定的人看到的样子。
真数据只留在本机 `data/try/`。
