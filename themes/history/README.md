# history：推分记录图

伊迪亚主题，背景使用作者选定的第 2 张：John Martin《万魔殿》。沿用霞鹜文楷、Segoe Script、难度颜色及总 Rating 色档。

## 横向版式

固定 2700×1780 CSS 像素，与背景油画的横幅比例接近。保留整幅风景，右侧完整展示伊迪亚立绘，包含头发、衣摆和鞋子，不用头像裁片。

左侧上方为抬头和整批概览，下方两张连续表格平行放置，曲目按行列出：

- B50 构成变化：新进、移出和席位内提升，最多 7 项；先新进、再移出、最后席位内提升，各组按单曲 Rating 降序排列。曲名保持普通文字色，仅状态与数值用绿色 / 红色。
- 本次成绩更新：分数前后、单曲 Rating、FC/AJ 与 B50 状态，最多 8 张谱面；按更新后的单曲 Rating 从高到低排列；B50 外成绩同样参与排序。

两张表的曲名统一用浅雾蓝、左侧细竖线和淡底色，与下一行暖色分数、红绿涨幅区分，沿用霞鹜文楷。两张表均在难度标识旁展示单曲定数（一位小数，沿用数字字体，文字跟随难度颜色）；移出谱面也保留定数。ULT 的难度标识是近黑底，定数取底色的同一色相、只提亮到刚好认得出的暗灰紫，比别的难度暗、跟黑底标识对得上（不跟砖红边框走）；用实心字不描边，描边缩小后会吞掉数字笔画。

超出时明确注明未展开的数量。总数、B50 均值和涨幅始终按整批完整数据计算。两张表的长曲名都只放一行，超长省略；明细表可先缩小到 26px；图片不随数据量变高。不画逐曲独立卡片。

画框使用大都会博物馆实物照片裁片，保留黑木、暗红嵌石、蓝色角石。表格采用伊迪亚黑袍的花叶纹理，标题底取象牙色衣料裁片；素材均为现有图片的确定性裁切和拼接，没有生成式 AI 图像。来源见 [assets/README.md](assets/README.md)。

## 数据与指令

- 只有 `/推分记录`，只看最近一次更新；日期选项、`最新` 参数和翻页均已移除。
- `src/history.cjs` 按上传时间归批、补历史、从基线重放 B50；`src/history-view.cjs` 明细只取最后一批、按单曲 Rating 降序截取展示行。
- 右侧立绘等比例放大并以 0.60 不透明度融入背景，完整保留头发、衣摆与鞋子。仅看最近一次更新，不展示 Rating 折线图。
- 当前 Rating 与本次前后 B50 均值都使用共享 Rating 色阶；17.00 起的虹极照 best 用上暖下冷的饱和竖渐变，16 段虹保持浅色横向，两者要分得出来。整批提升使用独立冰蓝白渐变，成绩提升为绿色、移出为红色。
- 「B50 构成变化」和「本次成绩更新」两张表里的小 Rating 保持普通文字色（涨幅仍用绿 / 红），不套 Rating 色阶。
- 当前 Rating 沿用两位截断；本次前后重算值标为「B50 均值」，展示三位小数。单曲 Rating 保留最多四位。
- 时间用北京时间。相邻上传时间不超过 15 秒归为一批，不是落雪原生批次 ID，也不是每次游玩记录。
- B50 外成绩和同分 FC/AJ 提升仍可显示，没有改变 B50 时保留明确的空状态。
- 无成绩或无推分记录时回文字。有记录走 `ctx.image`，JPEG 76、1.5 倍输出（4050×2670）。

## 预览

```powershell
node tools/render-preview.cjs history --out themes/history/previews/landscape.jpg --scale 1.5
node tools/render-preview.cjs history themes/history/examples/latest.json --out themes/history/previews/latest.jpg --scale 1.5
```

示例均为虚构成绩。`design/make-example.cjs` 用正式 report 整理流程生成示例，`design/prepare-materials.py` 保存素材裁切坐标。真实账号数据只留在本机 `data/try/`，不写入示例、不发送 QQ 消息。

实测输出约 1.1–1.2 MB。不使用整页模糊或 SVG 噪声滤镜；字体、图像加载完成后调用 `ThemeKit.done`。
