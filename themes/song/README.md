# song：单曲成绩图

`/单曲` 用的主题（功能代码在 `src/features/song.cjs`）。跟 `/b50` 一套样子（金框、烧焦撕边的羊皮纸、手写字），
画面换成跟西比拉精灵记火之巫女ティータ・アヴェニアス（泰达·艾薇妮娅斯）有关的一幅：

- **背景是一幅油画**：John Martin《所多玛与蛾摩拉的毁灭》（1852，公有领域）—— 火雨烧城，对上泰达一夜烧光圣都的剧情。
  作者挑它还因为画里人物少，正文盖上去以后不乱。画布 16:10（1824×1140），跟 MiaBot 的单曲图一个比例，油画原图也差不多是这个比例。
- **右边淡淡地叠着泰达的立绘**：普通版、左右镜像（朝左看着正文）、不透明度 50%（38% 时镜像后身上几处看不清），
  左边、脚下、头顶三面渐隐，颜色往油画的暖褐调了一点。立绘透明时，油画右边悬崖上的罗得父女（白袍）会从她腿上透出来，
  所以那里叠了一团暗烟把他们压下去（`theme.css` 的 `.smudge`，坐标是在画布上量的）。
- **正文全在左边**（照作者给的参考图：一张 maimai 单曲卡片的上半部分），右边整块留给立绘；左边铺一层从深到无的暗幕，字底下够暗。
  正文宽 1100（原来 1000，作者 2026-10-16 让右边界往右挪，挡住一点立绘也没关系）。
- **曲绘在左上角，套一个小金框**：跟外面的大框用同一张素材按 0.15 缩小拼的，像挂在画里的另一幅小画。
  缩到这么小时线脚不能一段段交替铺（每段只有 18 像素，接缝透出一道道黑线），直边改成整条拉长。
- **曲绘右边**：曲名（一行，放不下先缩、最小 38px，再放不下用省略号）、曲师、版本 / 分类 / BPM / ID 四个小格，
  下面一行是对应角色（原创、彩绿、音击舞萌的曲子才有）和日服上线日期，这两样来自 `src/data/song-extras.json`。
  对应角色：落雪的 128 见方头像做成小圆章，好几个角色时叠着放（四个以上叠得更紧），后面写名字；国服缺这张卡时借同一个人
  别的卡的头像；落雪里根本没这个人的，用从 wikiwiki 立绘上截的头像（`npm run character-icons`，图在
  `themes/shared/icons/character-jp/`，不进仓库），没截的不画圆章、只写名字。名字连起来放不下时一级级写短：全名 →
  只写人名（去掉「／」后面卡名的副标题）→「第一个人 等 6 人」，每一级先缩字、最小 24px（六个人的全名缩到放得下就看不清了）。
- **一行一个难度**，底板是拉丝黑铁板、金色描边、四角铆钉（配泰达「铁之国」アギディス的出身和她的黑金盔甲；作者在它和烟熏玻璃之间选的）。
  从左到右：难度色块写定数（WE 写属性汉字和星级）｜分数（下面一行小字：物量在前、谱师在后，谱师太长只截它）｜评级封印｜
  FC/AJ、通关、FULL CHAIN 小牌子｜单曲 Rating。封印和标记往左靠、跟 Rating 隔开一段（CATASTROPHY 紧挨着数字时看着挤）。
  行高最多 152：四五个难度正好铺满，WE 只有一行时不拉成一大块。没打过的谱面分数和 Rating 写一条横线。
- 难度颜料色、评级封印（金属：SSS+ 虹彩金、SSS 金、SS 银、S 铜、AAA 往下暗铁）、通关标记、手写字体都跟 best 主题一样
  （见 `../best/README.md`）：正文霞鹜文楷，数字 Segoe Script。
- **字号**（作者 2026-10-16 嫌小、放大过两轮）：难度名 24px、跟定数之间空 8px，物量和谱师 27px、跟分数之间空 10px，
  四个小格和对应角色、日服上线的标签 22px，页脚 26px。其中难度名、物量谱师那行、几个标签是**加粗**的，
  跟 best 主题一样用 fonts.css 的 `Anna Hand Bold`（文楷只有 Medium 一个字重，让浏览器在上面描粗）。
- **页脚**只写「Generated by Anna Bot · 数据来自落雪查分器 · 时间」，不写玩家名（作者让去掉的）。

## 素材

见 `assets/README.md`。金框用 `../best/assets/frame.png`。

## 数据

`src/features/song.cjs` 的 `buildData` 给出，形状看 `examples/preview-data.json`（原创曲、有对应角色）、`examples/ultima.json`（五个难度、BASIC 没打过）
和 `examples/characters.json`（六个对应角色，有一个只有名字）。
示例数据的曲目是真的、分数是编的。

## 预览

```
npm run theme -- song                                                          实时预览
npm run preview -- song --out themes/song/previews/muspell.jpg                  正式出图流程渲染
npm run preview -- song themes/song/examples/ultima.json --out themes/song/previews/ultima.jpg
```

出图是 2040×1356 CSS 像素、两倍输出（4080×2712），JPEG 质量 76，约 1.2～1.3 MB。
