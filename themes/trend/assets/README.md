# 梅薇素材

- `meve-fullbody.png`：原初の巫女メーヴェ（Möwe, Original Sibyl）完整透明立绘，原图未经改动。游戏角色插画，插画作者 Maeka，非公有领域。
  [文件来源](https://chunithmstory.miraheze.org/wiki/File:M%C3%B6we,_Original_Sibyl_Fullbody.png)。
- `painting.jpg`：居斯塔夫·库尔贝《阵风》（The Gust of Wind），作者选定的背景候选 07，公有领域绘画。
  [高清原图来源](https://commons.wikimedia.org/wiki/File:Gustave_Courbet_-_The_Gust_of_Wind_-_Google_Art_Project.jpg)。
- `frame-original.jpg`：Met 的 Cassetta frame，意大利威尼托，16 世纪中期，藏品号 1975.1.2102；作者选定 N1。馆藏开放图像。
  [馆藏与原图](https://www.metmuseum.org/art/collection/search/461636)。
  正式主题以 Canvas 等比例切片拼接成细横框，原始照片不修改。具体坐标和缩放比见 `../renderer/frame.js`。

素材随本机部署包分发，不进 Git，须与主题一起保存。
