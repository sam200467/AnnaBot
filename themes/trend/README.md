# 分表变化：原初的风之巫女梅薇

已接入并完成第二版排版调整：背景为作者选定的 07 库尔贝《阵风》，画框为 N1 蓝绿底金色卷草框（Met 1975.1.2102），按作者要求变细且不拉伸花纹。

## 已确认的要求

- 这是独立新功能；现有 `/推分记录` 的功能代码和排版不改。
- 仅支持 `/分表变化 本周`、`/分表变化 本月`。
- 横版，左侧较大的 B50 折线图；右侧上下排列较小的 B30、N20 图；完整立绘融入油画。
- 字体、绘画质感沿用现有主题；底板按梅薇的靛蓝衣料、米白袖口、旧金饰边、翡翠短剑设计。
- 多个背景、画框候选必须先让作者选择，不能自行定稿。

## 计算与时间

`src/trend.cjs` 读取 `history.cjs` 已有的 `replay` 结果，不改旧模块。B50 按 50 个席位、旧曲 B30 按 30 个席位、新曲 N20 按 20 个席位计算均值，空位按零计。B50 = B30 × 0.6 + N20 × 0.4。

使用北京时间的自然周（周一零点起）、自然月（一号零点起），截至查询时刻。保留区间内每个上传批次，不因月内上传多而删点；区间起点和查询时刻补持平端点，无更新也能画持平线。按当前定数、新旧曲分组重放，不能视为跨版本的原始官方 Rating 快照。

`src/features/trend.cjs` 是独立功能入口，在功能清单注册 `trend`；`test/trend.test.cjs` 覆盖时间边界、三部分均值、席位替换、大量批次、持平数据和缓存复用。只接受授权绑定；区间内没有更新也展示持平曲线。

顶部统计为「本周/本月内 B50 共 X 个谱面成绩更新」：比较区间首尾的 B50，按曲目＋难度去重。最后仍在 B50 的原席位成绩或连段标记变化计一个，新进计一个，被顶替移出的不额外计数；同一谱面多次更新只计一次，榜外更新不计入。

## 排版与画框

- 固定横版 2700×1620；左侧 B50 占两行，右侧 B30 / N20 上下堆叠，最右侧完整立绘。移除角色落款、顶部「西比拉精灵记 · 风之手记」和玩家名，日期与更新统计放大，裁掉多余底部留白。
- 图表用普通折线连接上传批次的采样点，不使用阶梯线或平滑曲线。三张图各用独立纵轴，当前值和区间变化显示四位小数；小图最多三个日期刻度，但不裁掉曲线点。
- 当前均值与「原均值」按共享 `ThemeKit.ratingTier` 分档上色；正向变化用梅薇短剑的翡翠绿，负向变化保留红色。
- 16 段虹是浅色横向渐层；17.00 起的虹极照 best 的暗底配色，用上暖下冷的**竖渐变、饱和色**，不能再用浅粉彩，否则在靛蓝底上跟 16 段几乎一样（17.23 会被看成没上对色）。
- Rating 显示四位小数时按截断、不四舍五入，颜色档和屏幕上的数字才一致（16.99996 不能显示成 17.0000 却还按 16 段上色）。
- 面板取靛蓝衣料，标题条取袖口米白，曲线用翡翠绿、灰紫与浅金；底纹来自梅薇立绘中的衣料裁片。
- `renderer/frame.js` 直接读取 N1 实物照片。坐标以 545px 宽缩略图为标尺，四角和每一段边条均使用同一个 0.62 缩放比，边条重复拼接，末段裁余；没有横向或纵向单独拉伸，也不做透视变形。
- 成品左右框宽约 45–46px，上下约 55–58px；原框的不等宽比例也保留。Canvas 随画布尺寸重新拼接，以 2 倍绘制，最终 JPEG 质量 76、1.5 倍输出（4050×2430），本机预览约 1.1 MB。
- 预览：`node tools/render-preview.cjs trend --out themes/trend/previews/month.jpg --scale 1.5`。示例数据是虚构数据，图片上会注明。
- 颜色回归：`node tools/render-preview.cjs trend themes/trend/examples/rating-tiers.json --out themes/trend/previews/rating-tiers.jpg --scale 1.5`（B30 17.23 / B50 17.134 是虹极，N20 16.99 是虹）。
