# 谱师名义与完整马甲明细

来源：wikiwiki.jp 的谱师汇总页 1～5。只归并单人栏目中的明确署名和别名，不把推测身份当成事实。
同一组中可能出现带 vs 的“一人合作”署名；真实合作栏的署名不拆给个人。来源位置、对应曲目和难度保存在归属 JSON 的 evidenceByCredit 中。
零张的名字是 wiki 明确指向该人的别名，当前国服曲库里没有以此名字署名的紫谱或黑谱。

返回 [别名填写清单](chart-designers.md)。
